# YouTube Niche Parser

Локальний веб-інструмент для пошуку перспективних ніш на YouTube під різні гео.
Шукає відео за твоїми ключовими словами через офіційний **YouTube Data API v3**
і виділяє канали з хорошими переглядами, які при цьому **нові** і/або мають
**мало відео** — тобто органічно "вистрілили" і являють собою робочу нішу/формат.

## 1. Отримати безкоштовний API-ключ YouTube Data API v3

1. Відкрий https://console.cloud.google.com/ і увійди своїм Google-акаунтом.
2. Створи новий проєкт (кнопка вибору проєкту вгорі → "New Project"), назви як завгодно, напр. `youtube-niche-parser`.
3. У меню зліва: **APIs & Services → Library**, у пошуку введи `YouTube Data API v3`, відкрий і натисни **Enable**.
4. Перейди в **APIs & Services → Credentials → Create Credentials → API key**.
5. Скопіюй згенерований ключ.
6. (Рекомендовано) Натисни "Restrict key" і обмеж його лише до `YouTube Data API v3`, щоб ключ не міг використовуватись для інших API.

Безкоштовна квота — **10 000 unit на добу**. Один пошуковий запит (`search.list`)
коштує 100 unit, тому це приблизно **100 пошуків на день** (по одному ключовому
слову й сторінці; для фільтра "Тільки довгі" — 200 unit/слово, бо опитується два
діапазони тривалості). У верхньому правому куті інтерфейсу видно, **скільки unit
залишилось сьогодні** — лічильник зберігається на диску (`app/data/quota_state.json`)
і не обнуляється при перезапуску сервера, скидається раз на добу опівночі за
тихоокеанським часом (саме тоді Google скидає реальну квоту).

## 2. Встановлення

```bash
cd E:/YouTube/parser
pip install -r requirements.txt
```

Створи файл `.env` у корені проєкту на основі `.env.example`:

```
YOUTUBE_API_KEY=встав_сюди_свій_ключ
```

## 3. Запуск

```bash
uvicorn app.main:app --reload
```

Відкрий у браузері: http://127.0.0.1:8000

## 4. Як користуватись

1. Введи ключові слова/теми (кожне з нового рядка) — це і є пошук ніш.
2. Обери гео (регіон пошуку YouTube) та період — довільна кількість останніх днів
   (є chips-кнопки для швидкого вибору 1/2/7/30/90/180/365, або впиши своє число).
3. Обери **тип відео**: всі / тільки Shorts (≤3 хв) / тільки довгі (>3 хв).
4. Задай пороги фільтрів:
   - **Мін. переглядів на відео (за період)** — поріг саме для знайденого відео.
     Це головне поле для сценарію "знайти відео за останні 2 дні з 10 000+ переглядів":
     постав період = 2, це поле = 10000, і вимкни чекбокс "Застосовувати фільтр каналу"
     нижче, якщо хочеш чисто "гарячі" відео незалежно від віку/розміру каналу.
   - **Мін. середні перегляди/відео каналу (опційно)** — відсікає канали з низьким охопленням
     в цілому. Порожнє поле = фільтр вимкнено (не застосовується).
   - **Макс. к-сть відео** та **Макс. вік каналу** — разом з чекбоксом "Застосовувати
     фільтр каналу: новий АБО мало відео" (увімкнено за замовчуванням) визначають
     "перспективність" каналу.
   - Опційно — діапазон підписників, щоб відсіяти вже "розкручені" канали.
5. Натисни **"Шукати ніші"**. Результати можна сортувати кліком по заголовку колонки.
6. **Export CSV** — вивантажує поточну таблицю результатів у файл.
7. **📈** на рядку каналу — відкриває графік росту каналу (див. нижче).
8. **🕘 Історія пошуків** — кожен пошук зберігається локально (SQLite, `app/data/`).
   👁 показує збережені результати без нового запиту до API (не витрачає квоту),
   🔁 повторює той самий пошук зараз, 🗑 видаляє запис.

`Score` — евристичний рейтинг (перегляди/відео, помножені на "концентрацію"
успіху малою кількістю відео та свіжість каналу). Це орієнтир для сортування,
а не точна метрика — завжди дивись на конкретні цифри поруч.

### Графік росту каналу

Графік будується по **даті публікації та сумарних переглядах кожного відео** каналу
(накопичена сума в часі), з позначками "★ Пік" (відео з найбільшими переглядами) і
"🚀 Прорив" (перший різкий стрибок переглядів відносно попередніх відео).

**Важливо:** YouTube Data API (публічний) не дає щоденної статистики переглядів
чужого каналу — це приватні дані, доступні лише власнику каналу в YouTube Studio
через окремий, авторизований YouTube Analytics API. Тому цей графік — наближення
"на якому відео канал вистрілив" за публічними даними по відео, а не точна
щоденна аналітика зсередини YouTube Studio.

## Обмеження

- Тільки ручний пошук за запитом (без фонового автосканування за розкладом — заплановано на майбутні версії).
- Гео визначається через параметр пошуку YouTube (`regionCode`) — це "що популярне в цьому регіоні",
  а не гарантія, що сам канал зареєстрований у цій країні (поле країни каналу показується в таблиці окремо, коли воно заповнене автором).
- Немає кешування самого пошуку (тільки історія вже виконаних пошуків) — кожен новий пошук витрачає квоту API.
- Графік росту каналу для каналів із дуже великою кількістю відео (>200) показує лише перші 200 за плейлистом завантажень — квота під контролем, про обмеження є попередження в модалці.
