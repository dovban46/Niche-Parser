# 1. ГАЧОК
Що найчастіше кладе в сумку бабуся, / яка їде до дітей у Європу? / Сало? / Ні. / Аптечку. / Корвалол, цитрамон, анальгін, / щось від тиску і щось для сну.
А тепер питання. / Яка з цих звичних пляшечок / може стати проблемою на кордоні? / Підказка: та, що стоїть майже в кожній українській шафці.
Сьогодні граємо в гру. / Пані Ганна з Полтави їде / потягом до доньки в Мюнхен. / У її сумці сім ліків. / Ми перевіримо кожен і поставимо оцінку: зелений, / жовтий чи червоний. / А ви вгадуйте разом з нами, / скільки червоних буде наприкінці.
І одна річ вас здивує: найвідоміші ліки, / які у Швеції колись прибрали з полиць, / у Німеччині досі продають. / Про це в середині.
А наприкінці ми проведемо пані Ганну через кордон / у Перемишлі й подивимося, / що з її сумки доїде до Мюнхена.
# 2. ПІДПИСКА
Ми робимо такі розбори для тих, / хто їздить до рідних за кордон. / Якщо вам це корисно, / підпишіться на канал і поставте лайк. / Так наступне відео не загубиться.
# 3. АПТЕЧКА
Спершу коротко, як це працює. / Єдиного списку ліків, заборонених в усьому Євросоюзі, немає. / У Польщі свої правила, у Німеччині свої.
Але є три загальні речі. / Перше: ліки мають бути для вас, / а не на продаж. / Тобто стільки, скільки потрібно на поїздку. / Друге: в оригінальній упаковці, з інструкцією. / Третє: якщо ліки рецептурні, / з собою рецепт або довідка від лікаря.
І є окрема група. / Ліки, в яких є речовини, / що діють на нервову систему сильніше за звичайні. / Їх у Європі називають контрольованими. / З ними справа серйозніша: потрібні документи, / і без них можуть бути проблеми.
Тепер відкриваємо сумку пані Ганни.
# 4. КОРВАЛОЛ
Перша пляшечка. / Корвалол. / Його знає кожен. / Від серця, від нервів, щоб заснути.
Але подивіться на склад. / Там є фенобарбітал. / Це барбітурат, старий заспокійливий засіб. / І ще з тисяча дев'ятсот сімдесят першого року він / у міжнародному списку психотропних речовин ООН.
Що це означає на практиці? / У Німеччині фенобарбітал входить / у закон про наркотичні засоби. / Тобто це не просто краплі, / а контрольований препарат. / А в Польщі, / щоб перевезти через кордон ліки з психотропними речовинами, / потрібен спеціальний документ від головного фармацевтичного інспектора. / Він видається на підставі рецепта.
А ось цікава деталь. / У німецьких аптеках є краплі / з дуже схожою назвою, Валокордин. / Але сьогодні в них зовсім інша діюча речовина, без фенобарбіталу. / Тобто знайома назва є, / а того самого складу немає.
Чи заберуть корвалол у пані Ганни? / Гарантувати не можна ні те, ні інше. / В інтернеті пишуть, / що його заборонили в десятку країн, / але офіційних підтверджень для / кожної країни я не знайшов. / Чесно скажу так: без рецепта це ризик.
Оцінка: червоний. / Не тому, що це злочин, а тому, / що без документів це найімовірніше місце, / де виникне проблема.
Рахунок: червоний один.
# 5. ЦИТРАМОН
Друга. / Цитрамон. / Аспірин, парацетамол і кофеїн.
Тут усе спокійно. / У Німеччині продають знеболювальні / з таким самим набором речовин, / просто під іншою назвою. / Звичайні ліки від головного болю, без рецепта.
Цікаво, що саме цитрамон часто бояться везти, / бо в ньому кофеїн. / Мовляв, це ж збудливе. / Але кофеїну там стільки ж, / скільки в половині чашки кави. / Митника це не цікавить.
Оцінка: зелений. / Беріть стільки, скільки треба на поїздку, / в коробці з інструкцією.
Рахунок: зелений один, червоний один.
# 6. АНАЛЬГІН
Третя. / Анальгін. / Ось обіцяна історія.
Анальгін, по-науковому метамізол, / у Швеції в сімдесятих зняли з продажу. / Причина: рідкісна, але небезпечна реакція, / коли в крові різко падає кількість білих клітин. / Його повертали, а в тисяча дев'ятсот / дев'яносто дев'ятому році прибрали остаточно. / У США його теж давно немає.
І багато хто з цього робить висновок: / анальгін заборонений у Європі. / А от і ні.
У Німеччині метамізол досі один із найпоширеніших знеболювальних. / Наприкінці дві тисячі двадцять четвертого року Європейська / комісія вирішила залишити його на ринку Євросоюзу. / Правда, з посиленими попередженнями. / А от Фінляндія свій препарат відкликала.
Тож одна країна прибрала, сусідня продає. / Ось вам і «вся Європа».
Оцінка: зелений, але з приміткою. / У Німеччині такі ліки зазвичай за рецептом, / тож у великій кількості краще не везти.
Рахунок: зелений два, червоний один.
# 7. ФЕНІБУТ
Четверта. / Фенібут. / Його п'ють від тривоги і для сну, / в Україні він звичний.
А тепер увага. / У Німеччині фенібут не зареєстрований як ліки взагалі. / Він потрапив під закон про нові психоактивні речовини.
Угорщина внесла його в список заборонених / у дві тисячі вісімнадцятому році. / Італія і Франція у дві тисячі двадцятому. / У Франції заборонили не лише продаж, / а й зберігання.
Тобто те, що вдома лежить поруч із валеріанкою, / в кількох країнах Європи стоїть / в одному списку з речовинами, / які продають у темних провулках.
Оцінка: червоний. / Без варіантів.
Рахунок: зелений два, червоний два.
# 8. ВАЛІДОЛ
П'ята. / Валідол. / Таблетка під язик, коли щось кольнуло.
Жодної заборони на валідол я не знайшов. / Але є смішна деталь: / у європейських аптеках його майже не продають, / там такого звичаю немає. / Тож донька пані Ганни, швидше за все, / в аптеці його не знайде.
І ще одна порада для пані Ганни. / Якщо валідол для неї звичка, / а серце справді турбує, / краще заздалегідь спитати лікаря, що робити, / якщо в поїздці стане погано. / Бо валідол заспокоює, але не лікує серце.
Оцінка: зелений.
Рахунок: зелений три, червоний два.
# 9. НІМЕСИЛ
Шоста. / Пакетик німесилу, порошок від болю й температури. / Діюча речовина німесулід.
У дві тисячі сьомому році / Ірландія призупинила продаж таких ліків, / бо були випадки важкого ураження печінки. / А у дві тисячі дванадцятому Євросоюз обмежив їх: / курс не більше п'ятнадцяти днів, / тільки за рецептом і тільки тоді, / коли інші ліки не допомогли.
Заборони немає. / Але для Європи це рецептурний препарат, / а не те, / що п'ють від кожного болю.
Оцінка: жовтий. / Якщо везете, то з рецептом і небагато.
Рахунок: зелений три, жовтий один, червоний два.
# 10. КОДЕЇН
І сьома. / Сироп чи таблетки від кашлю з кодеїном.
Кодеїн споріднений з опіоїдами. / У багатьох країнах Європи такі / ліки продають тільки за рецептом, / а в деяких для / перевезення потрібні ті самі документи, / що й для контрольованих.
Оцінка: жовтий. / Рецепт обов'язково, кількість тільки на поїздку.
Остаточний рахунок: три зелених, два жовтих, два червоних. / А ви вгадали?
# 10А. ЧОМУ ТАК СУВОРО
Логічне питання: чому Європа так прискіпується до того, / що в нас продають у кожній аптеці?
Відповідь у самих речовинах. / Барбітурати, як фенобарбітал, / колись були головними снодійними у світі. / Але з часом лікарі побачили два мінуси. / До них звикають, / і без них потім важко заснути. / А у великих дозах вони небезпечні, / особливо разом з алкоголем.
Тому в Європі / їх поступово замінили на інші ліки, / а самі барбітурати лишили під суворим контролем. / У нас же корвалол так / і залишився «бабусиними краплями», / які купують без рецепта.
Те саме з фенібутом. / У нас його реєструють як ліки. / А в Європі його довго продавали / в інтернеті як харчову добавку, / і люди почали ним зловживати. / Звідси і заборони.
Тобто це не про те, / що там не люблять українські ліки. / Просто дві системи по-різному вирішили, / що можна продавати вільно, а що ні.
І є ще одна причина. / Митник не знає, скільки вам насправді треба. / Він бачить сумку, / в якій десять пляшечок однакових крапель. / Для нього це питання: / для себе чи на продаж? / Тому кількість важить не менше, ніж назва.
# 11. МІФИ
Тепер швидко про міфи.
Перший: «везти можна двадцять таблеток будь-чого». / Такої цифри для всіх ліків / і всіх країн я / в офіційних джерелах не знайшов. / Правило інше: стільки, / скільки потрібно вам на поїздку.
Другий: «якщо ліки продаються в Україні без рецепта, / то і в Європі можна». / Ні. / Фенібут тому приклад.
Третій: «корвалол заборонений у всій Європі». / Так кажуть часто, / але насправді в кожної країни свої правила. / Проблема не в назві, / а у фенобарбіталі і в тому, / чи є у вас документи.
Четвертий: «скажу, що це для себе, і пропустять». / Для звичайних ліків так і є. / Для контрольованих слова не допоможуть, потрібен папір.
# 12. ЩО РОБИТИ
Ось простий порядок перед поїздкою.
Перше. / Подивіться склад своїх ліків, / а не лише назву. / Шукайте фенобарбітал, кодеїн, фенібут.
Друге. / Для рецептурних візьміть рецепт або довідку лікаря. / Добре, якщо в ній буде / міжнародна назва речовини й доза.
Третє. / Не пересипайте таблетки в пакетики. / Тільки в оригінальній коробці з інструкцією.
Четверте. / Перевірте правила країни, куди їдете. / Найнадійніше на сайті її посольства або митниці.
І п'яте. / Якщо ліки щоденні й важливі, / поговоріть з лікарем, / чим їх можна замінити на місці. / У Європі є аналоги майже всього.
# 12А. ПЕРЕМИШЛЬ
А тепер обіцяне. / Уявімо, як це могло б виглядати для пані Ганни.
Потяг зупиняється в Перемишлі. / До купе заходить польська митниця. / Звичне питання: що везете? / Пані Ганна відкриває сумку.
Якби вона послухала наші поради, / то вийшло б так. / Цитрамон, анальгін і валідол у коробках, / з інструкціями, на два тижні. / Німесил і сироп з рецептом від сімейного лікаря. / Корвалол і фенібут лишилися вдома, / а від лікаря довідка, / що їх можна замінити іншими препаратами.
Митниця дивиться на коробки, на рецепт, киває. / Сумку застібають. / Потяг рушає далі.
А якби пані Ганна поїхала так, / як їздить більшість? / Десять пляшечок корвалолу, / пачка фенібуту без рецепта і таблетки, / пересипані в пакетик, щоб займали менше місця. / Тут уже питання. / Що це за таблетки? / Чому так багато? / Де рецепт? / І кожне таке питання це втрачений час, / а можливо й ліки, / які лишаться на кордоні.
Різниця між двома поїздками не в удачі. / А в п'ятнадцяти хвилинах підготовки вдома.
# 13. ВИСНОВОК
Підсумуймо. / Цитрамон, анальгін і валідол пані Ганна довезе спокійно. / Німесил і ліки з кодеїном тільки з рецептом. / А корвалол і фенібут найкраще лишити вдома / або везти лише з документами від лікаря.
І головне: проблема не в тому, / що європейці не довіряють нашим лікам. / Просто речовини, які в нас звичні, / там стоять в іншому списку.
А тепер питання вам. / Які ліки ви або ваші / батьки завжди беруть у дорогу? / Чи бувало, що щось забирали на кордоні? / Напишіть у коментарях, це допоможе іншим.
І запам'ятайте: на кордоні дивляться не на назву на коробці, / а на те, що всередині.
