# 1. ГАЧОК
Це сир. / Він живий. / Усередині тисячі білих личинок, / і коли їх чіпаєш, / вони підстрибують на п'ятнадцять сантиметрів. / Тож такий сир їдять, прикриваючи порцію рукою.
Італія заборонила його ще шістдесят років тому. / А на Сардинії його тримають / у погребі й пригощають гостей.
І це не єдина заборонена їжа, / яку люди їдять досі. / Є риба, яка вбиває без протиотрути. / Пташка, яку президент Франції з'їв / за кілька днів до смерті. / І напій, який на сто років заборонили / в кількох країнах через одну газетну історію.
Зараз я покажу сім заборонених / і майже заборонених страв. / Чому їх заборонили. / І чому ніхто не збирається їх кидати.
Починаємо з сиру, / від якого тікають навіть італійці.
# 2. КАСУ МАРЦУ
Сардинія, Італія. / Вівчарі роблять сир з овечого молока. / А потім навмисно залишають його відкритим, / щоб сирна муха відклала в ньому яйця.
Із яєць виходять личинки. / Вони їдять сир зсередини / й розм'якшують його до майже рідкого стану. / Так народжується касу марцу. / Дослівно: «гнилий сир».
Тепер найцікавіше. / Їсти його треба живим. / Мертві личинки означають, що сир уже зіпсувався, / і місцеві такий не їдять. / А коли личинки відчувають небезпеку, вони підстрибують. / Приблизно на п'ятнадцять сантиметрів. / Тому гості прикривають свою порцію рукою.
Чому ж заборонено? / В Італії продаж такого сиру заборонили ще / у 1962 році, / бо це їжа, заражена личинками. / За правилами гігієни Євросоюзу його теж вважають забороненим.
Небезпека справжня. / Личинки можуть пережити шлунковий сік / і спричинити кишкові розлади. / Книга рекордів Гіннесса навіть назвала / його найнебезпечнішим сиром у світі.
Подають його на тонкому коржі пане карасау / й запивають червоним вином. / Свято це чи ні, залежить від господаря.
Але Сардинія не здається. / У 2005 році регіон навіть вніс / його до списку традиційних продуктів. / А за оцінками, / нелегально тут роблять приблизно сто тонн на рік.
Заборона є. / А вівчарі кажуть: це наша історія, / і вона вам не належить.
# 3. ФУГУ
Тепер Японія. / Риба фугу. / Її м'ясо вважають делікатесом. / А в її органах міститься тетродотоксин, / отрута без відомої протиотрути. / Вона набагато сильніша за ціанід.
Тому ніхто в Японії не може просто так узяти / й приготувати фугу в ресторані. / Потрібна ліцензія. / Її запровадили ще в 1958 році. / Кухарі вчаться кілька років, / а потім складають іспит із письмовою, / практичною частиною та визначенням риби. / Здає його лише близько третини.
А ще є печінка. / Це найотруйніший орган. / З 1980-х років її / не можна подавати в ресторанах.
Фугу ріжуть прозорими скибочками, / які просвічують крізь тарілку. / Кухар повинен знати, / де саме проходить межа між делікатесом і лікарнею.
Звучить так, ніби фугу заборонили. / Але ні: її не заборонили, / а загнали в жорсткі рамки. / Саме тому ресторанні отруєння тут рідкість.
Більшість отруєнь стається вдома. / Коли хтось купив рибу на ринку й вирішив, / що впорається сам.
Кажуть, навіть імператор Японії фугу не їсть. / Офіційного правила про це нема, / але таке переказують.
І тут головна думка. / Іноді заборона не вбиває традицію. / Вона просто змушує її бути обережною.
# 4. ОРТОЛАН
Тепер Франція. / Дрібна пташка ортолан, менша за долоню. / Її ловлять, тримають у темряві, / щоб вона відгодувалася, і топлять в арманьяку.
А далі її з'їдають цілою. / Разом з кістками. / Під серветкою. / Ніхто точно не знає, навіщо серветка: / щоб не втратити аромат, / щоб сховати обличчя від Бога / чи щоб не бачити, / як плюєш кістки.
У 1999 році Франція заборонила полювання на ортоланів. / Але закон довго ніхто не виконував. / Лише у 2007 році почали справжні перевірки. / Максимальний штраф на той час становив / кілька тисяч євро й до півроку в'язниці.
Причина проста: за десять років чисельність птахів упала приблизно / на тридцять відсотків.
Але найвідоміша історія / з цією пташкою пов'язана з президентом. / Наприкінці 1995 року, у новорічну ніч, / Франсуа Міттеран замовив ортолана на прощальну вечерю. / Він помер 8 січня 1996 року.
Для президента це була остання вечеря, / яку хотіли запам'ятати.
І досі на чорному ринку / один птах коштує сотні євро. / Бо найсмачніше те, що не можна.
# 5. ХАГГІС
Тепер Шотландія й США. / Хаггіс робиться з серця, / печінки й легень вівці, овсянки й спецій. / Усе це зашивають у шлунок тварини й варять.
У США його не продають. / Із 1971 року Міністерство сільського господарства / США забороняє легені овець у їжі. / Вважають, що в легенях може лишатися рідина зі шлунка, / і це ризик.
А легені в рецепті хаггіса становлять десять-п'ятнадцять відсотків. / Тож справжній шотландський хаггіс / у США продати не можна.
Що роблять американські шотландці? / Продають версію без легень. / Смак трохи інший. / Але ритуал той самий.
Тож, коли на шотландській вечері читають вірш Роберта Бернса / й урочисто розрізають хаггіс, / у США цю сцену відтворюють, / не маючи головного інгредієнта.
Бо Бернс писав свою «Оду хаггісу» / не для того, / щоб його читали над порожньою тарілкою.
# 6. АКІ
Тепер Ямайка. / Національний фрукт Ямайки називається акі. / Його їдять на сніданок із солоною рибою, / і це національна страва країни.
Але якщо фрукт недозрілий, він отруйний. / У ньому гіпогліцин А, / і через нього різко падає цукор у крові. / Це називають «ямайською блювотною хворобою».
У 1973 році США заборонили ввозити акі. / А з 2000 року дозволили / лише консервований акі від перевірених виробників. / Свіжий і досі не пускають.
А тепер про ціну помилки. / За кілька зимових місяців 2010-2011 років / на Ямайці підозрювали 194 випадки отруєння акі. / Двадцять три людини померли.
Тож ямайці їдять його лише тоді, / коли плід сам розкрився на дереві. / Відкритий плід показує, що він дозрів. / Закритий не рвуть ніколи. / Це правило знає кожна бабуся, / і воно рятує життя.
Заборону придумали далекі чиновники. / А справжній захист придумали бабусі.
# 7. АБСЕНТ
І нарешті напій. / Абсент. / Зелений, міцний, а в XIX столітті модний у Парижі. / Його пили художники й поети, / і навколо нього ходили чутки, / що він викликає галюцинації.
У 1905 році швейцарець Жан / Ланфре вбив дружину й двох дітей. / Він випив до цього абсент. / Але також випив вино й коньяк, багато коньяку. / Газети писали лише про абсент.
Швейцарія проголосувала за заборону у 1908 році, / і вона набула чинності у 1910-му. / Потім заборонили в США / у 1912-му й у Франції, / найпізніше, у 1915-му.
Скасували все пізніше. / Швейцарія у 2005 році. / США, фактично, у 2007-му. / Франція остаточно скасувала закон лише у 2011 році.
А що з туйоном, / через який лякали галюцинаціями? / Сьогодні його вміст у напої просто обмежують законом. / У Євросоюзі, наприклад, / до тридцяти п'яти міліграмів на кілограм.
Тож цілу епоху абсент вважали небезпечним / значною мірою через гучні газетні заголовки.
# 8. СУРСТРЕМІНГ
І ще один. / Його ніхто не забороняв. / Але його вигнали звідусіль.
Швеція. / Сурстремінг. / Це балтійський оселедець, / який місяцями бродить у бляшанці, / поки не набуде запаху, / що його порівнюють із чимось значно гіршим, / ніж протухлі яйця.
Законом його не заборонено. / Зате у 2006 році кілька авіакомпаній, / зокрема Air France, British Airways, / Finnair та KLM, / заборонили брати його на борт. / Бляшанка під тиском, / яка може вибухнути в літаку. / Тут вам і заборона.
А у 1984 році німецький суд / у Кельні підтримав виселення квартиранта. / Через те, що розсіл від сурстремінгу потрапив на балкон сусіда.
Сезон відкривають у третій четвер серпня. / І у Швеції на це чекають, / як на свято.
Тож заборонити можна навіть смак. / Але не можна заборонити людям про нього мріяти.
# 9. ЧОМУ ЗАБОРОНА НЕ ПРАЦЮЄ
Тепер подивімося на всі сім. / Касу марцу. / Фугу. / Ортолан. / Хаггіс. / Акі. / Абсент. / Сурстремінг.
Усі вони заборонені або обмежені. / І всі лишаються на столах. / Чому?
Це не про смак, / не про голод і навіть не про сміливість. / Це про ідентичність.
Бо заборона зазвичай відповідає на питання «чи небезпечно». / А люди їдять із іншого питання: / «хто я такий».
Для сардинського вівчаря сир із личинками / це не їжа. / Це доказ, що його предки були тут. / Для японського кухаря фугу це іспит, / який він склав. / Для ямайської бабусі акі це дім.
Але є й різниця. / Фугу й акі лишаються живими завдяки правилам: / ліцензії, дозрілому плоду. / А ортолан зникає, бо закон є, / а виконувати його довго ніхто не хотів.
Тож заборона працює лише тоді, / коли вона ще й навчає, / як їсти безпечно.
Питання тобі. / Яку з цих семи страв ти б спробував? / І яку не спробував би нізащо?
Напиши в коментарях. / І пам'ятай: інколи те, що не можна, / показує, що для людей справді важливе.
