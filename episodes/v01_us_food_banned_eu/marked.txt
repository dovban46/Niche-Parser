# 1. ГАЧОК
В Америці шоколадне яйце / Kinder Surprise вважають забороненим товаром. / За один лише рік митники / конфіскували понад шістдесят тисяч таких яєць.
А в Європі / не пустять на полицю американську курку. / Навіть задарма.
Здається дурницею, так? / Дві найбагатші частини світу ніяк не можуть домовитися, / що можна їсти.
Але ця суперечка триває понад тридцять років. / Вона дійшла до Світової організації торгівлі. / До мит на сир. / І до французького вівчаря, / який розібрав на частини цілий «Макдоналдс».
Зараз я покажу, / що саме з американської їжі Європа / не пускає до себе на стіл. / Чому. / І, головне, хто тут правий.
Бо відповідь не така очевидна, / як тобі розповідають в інтернеті.
Починаємо з курки, яку в Америці купають.
# 2. КУРКА У ХЛОРНІЙ ВАННІ
Уяви американську птахофабрику. / Тушки їдуть по лінії, одна за одною. / А в кінці їх занурюють / у великі ванни з холодною водою. / У воду додають антимікробний розчин: / хлор або пероцтову кислоту. / Навіщо? / Щоб убити сальмонелу та кампілобактер, / поки курка не потрапила до магазину.
У США це абсолютно законно й звично.
А тепер Європа. / Євросоюз такого не дозволяє: / тушки можна мити лише питною водою. / У 2008 році Єврокомісія пропонувала дозволити хімічну обробку, / але країни Євросоюзу проголосували проти. / Тож курку, яку так обробили, / на європейський ринок не пускають.
Це не страшилка з форумів. / Саме на «хлорній курці» / не раз спотикалися торговельні / переговори між США та Євросоюзом. / Британські політики лякали виборців нею під / час переговорів про вихід із Євросоюзу, / а американські фермери вважали / заборону просто захистом європейського ринку.
Дві сторони дивляться на одну / й ту саму тушку й бачать різне. / Для одних це безпека. / Для інших це торгівля, прикрита словом «безпека».
Але чому? / Невже європейці бояться хлору?
Не зовсім. / Їхня логіка така: ванна нічого не лікує. / Вона лише змиває сліди. / Брудна ферма, тісні клітки, антисанітарія на бійні, / а в кінці все «відмили», / і звіт чистий. / Тому в Європі правило інше: / чисто має бути на кожному кроці. / Від ферми до виделки. / А не лише на фініші.
Американці відповідають: ми нічого не ховаємо. / Ми просто додаємо ще один захист. / І хто ж відмовиться від додаткового захисту?
Найцікавіше, що наука тут не стає / на бік жодної зі сторін. / Європейське агентство з безпеки харчових продуктів у 2014 році / оцінювало пероцтову кислоту / й токсичної загрози для споживача не знайшло. / Але питання не лише в тому, / чи небезпечна ванна. / А в тому, / що вона дозволяє не помічати.
Ти, мабуть, чув про «ніжки Буша». / У 1990 році Буш / і Горбачов домовилися про / постачання американської курки в Союз. / Американці люблять білу грудку, / а темне м'ясо лишалося зайвим. / Його й везли нам, / і окорочки прозвали «ніжками Буша». / Вони заполонили ринки. / Ми їли їх роками. / І ніхто тоді не питав, / у чому їх купали.
До речі, Росія з початку 2010 року теж / обмежила ввезення американської курки через хлорну обробку. / Пізніше американські виробники змінили спосіб, / і ввезення відновили.
Скажу чесно, мене в цій історії дивує інше. / Ми роками сперечаємося, хто правий, / а самої курки це майже не стосується. / Вона просто лежить на полиці й чекає, / поки політики домовляться.
Але курка це лише розминка. / Справжня війна почалася через яловичину. / І закінчилася розібраним «Макдоналдсом».
# 3. ГОРМОНИ, РОКФОР І ВІВЧАР
Яловичина. / В Америці бичкам давали гормони росту. / Це дешево: бик швидше набирає вагу, / м'яса більше, ціна нижча. / Ковбой щасливий. / Покупець теж.
У Європі інакше. / З кінця вісімдесятих тут заборонили / гормони росту для м'ясної худоби. / А з 1989 року заборонили / й ввозити таку яловичину. / Європейці були налякані: / у 1980 році в Італії / в дитячому харчуванні з телятини знайшли синтетичний гормон, / і довіра зникла.
Америка не стерпіла / й подала скаргу до Світової організації торгівлі. / У 1998 році та вирішила: / Європа не довела, що така яловичина небезпечна. / Заборона, мовляв, не підкріплена достатньою оцінкою ризику.
Європа відповіла: ми все одно не пустимо.
Тоді США зробили те, / що роблять у такій війні. / Вдарили по гаманцю. / У 1999 році вони ввели мито / в сто відсотків на добірку європейських товарів. / Ціна вдвічі. / Під удар потрапили європейські делікатеси, / зокрема сир рокфор.
Рокфор. / Синій овечий сир із півдня Франції. / Його роблять на плато Ларзак.
І ось тут з'являється герой нашої історії. / Жозе Бове. / Французький вівчар, який сам робив рокфор. / Його сир раптом став удвічі дорожчим для американців, / а отже, втратив ринок.
Бове вирішив діяти. / 12 серпня 1999 року він / і ще кілька людей прийшли в містечко Мійо, / де будували новий «Макдоналдс». / А підтримати їх зійшлися сотні. / І будівлю розібрали на частини.
Для нього «Макдоналдс» був не рестораном, а символом. / Символом їжі, яку виробляють у величезних кількостях / і нав'язують усім однакову. / Французи придумали для неї слово «мальбуф», / тобто погана їжа.
Бове судили. / У 2000 році суд / дав йому три місяці в'язниці. / Звичайний вівчар став символом цілого руху, / а його боротьба за право країни самій вирішувати, / що лежить на її столах, / стала відомою далеко за межі Франції.
Хоч би що ти думав про його вчинок, / але мито вдарило саме по таких, як він.
Кумедний епізод? / Так. / Але він показує серйозну річ: / їжа це не лише обід. / Це гроші, закони, / фермери й гордість цілої країни.
Тепер головне запитання. / Чи небезпечна та яловичина з гормонами?
Чесна відповідь не «так» і не «ні». / Наукові комітети Євросоюзу застерігали щодо одного з гормонів, / естрадіолу, і казали, / що безпечного рівня встановити не можуть. / А американські регулятори вважають залишки у м'ясі безпечними. / Світова організація торгівлі ж сказала лише одне: / Європа недостатньо довела небезпеку. / А «не доведено» це не те саме, що «безпечно».
Пізніше сторони домовилися про компроміс: / Європа відкрила квоту для яловичини без гормонів, / а США поступово знизили мита.
Така сама історія з рактопаміном. / Це добавка в корм свиней, / щоб росло більше м'язів. / У США дозволена. / У Євросоюзі, Китаї та Росії заборонена.
Зупинись на секунду й згадай: / що з цього ти вже їв, / навіть не здогадуючись? / Курячі окорочки, свинину, хліб із фастфуду, яскраві цукерки. / Більшість із цього лежить і на наших полицях. / Тому наступна частина стосується не «їх», а тебе.
Але найбільше суперечок викликає не м'ясо. / А звичайний хліб.
# 4. ХЛІБ З ПІНОПЛАСТОМ І БАРВНИКИ
У 2014 році американська блогерка Вані Харі, / відома як Food Babe, / зібрала петицію проти мережі Subway. / Причина: у хлібі була речовина азодикарбонамід. / Вона робить тісто пишнішим. / Але її ж використовують у виробництві піноматеріалів, / зокрема килимків для йоги. / Саме ця деталь і розлетілася по інтернету.
Subway заявила, що прибирає добавку з рецептів. / А в Євросоюзі вона / для харчових продуктів не дозволена.
То чи отруївся б ти таким бутербродом? / Американські регулятори вважали кількість допустимою. / Тож це не вбивця. / Просто Європа не дала їй дозволу.
Зверни увагу на закономірність. / Спочатку добавка роками лежить / у складі й нікого не цікавить. / Потім хтось знаходить в інтернеті кумедний факт, / і за кілька тижнів величезна мережа її прибирає. / Не суд, не закон, а один допис. / Ось яка сила в історії, / яку легко переказати.
Інший приклад: бромат калію. / Його додавали в борошно, / щоб тісто краще піднімалося. / У Євросоюзі, Британії та Канаді він заборонений. / У США його довго дозволяли. / Лише Каліфорнія у 2023 році ухвалила закон, / який забороняє його з 2027 року.
Є ще барвники. / Після британського дослідження 2007 року на європейських продуктах із / шістьма синтетичними барвниками / з 2010 року мусять писати попередження: / вони можуть погано впливати / на активність і увагу дітей. / Заборони немає. / Але хто купить цукерки з таким написом? / Тому європейські виробники часто / просто міняли барвники на натуральні, / а в США лишали яскраві.
Втім, Америка й сама потроху наздоганяє. / У 2024 році там скасували дозвіл / на бромовану олію, / яку клали в газовані напої. / А в січні 2025-го Управління з продуктів / і ліків ухвалило прибрати / з їжі барвник Червоний №3 до 2027 року.
Тобто історія не про те, / що Європа розумна, а Америка відстала. / Бо тепер дзеркало.
# 5. ГМО, ЯКЕ НЕ ТАК СТРАШНЕ
Є ще одне слово, / яке лякає в Європі найбільше. / ГМО.
Генетично модифікована кукурудза та соя / в США це майже все поле. / У Європі інакше. / Кожен такий продукт має пройти окремий дозвіл, / на етикетці обов'язково пишуть, що він модифікований, / а вирощують там лише один сорт кукурудзи, / переважно в Іспанії.
І ось тут цікаво. / Європейські наукові органи, / зокрема те саме агентство з безпеки харчових продуктів, / кожен схвалений продукт оцінило / й загрози для безпеки не знайшло. / Тобто заборона тут не стільки про науку, / скільки про довіру. / Європейці просто не хочуть, / щоб за них вирішували.
Чи це погано? / Не обов'язково. / Людина має право знати, що вона їсть, / і вирішувати сама. / Але це чесніше назвати не «небезпечно», / а «ми не згодні».
Запам'ятай цей прийом, бо він повторюється. / Коли чуєш «в Європі це заборонено», / спитай себе, що саме заборонено. / Небезпеку довели? / Чи просто не дозволили, / бо ніхто не довів протилежного? / Це дві різні історії, / і з них виростають дві різні тарілки.
# 6. ДЗЕРКАЛО: ЩО АМЕРИКА ЗАБОРОНИЛА У НАС
Тепер у дзеркало. / Бо Америка теж має / що заборонити з європейського столу.
Kinder Surprise. / Ще з 1938 року / американський закон забороняє продавати солодощі, / у які вбудований неїстівний предмет. / Іграшка всередині шоколаду це якраз він. / Тому митники конфіскують ці яйця й знищують їх. / Виробник знайшов вихід: Kinder Joy, / де іграшка лежить в окремій половинці. / З нею в США можна.
Ще приклад. / Сир із сирого молока. / В Америці його можна продавати / лише після витримки щонайменше шістдесят днів. / Для багатьох м'яких французьких сирів це забагато, / і вони там просто не виживають.
У кожного свій страх. / Європейці бояться хімії у їжі. / Американці бояться мікробів і того, / що дитина проковтне іграшку.
І обидва страхи мають під собою причини. / Просто кожна країна пережила свої скандали / й побудувала закони навколо власного болю. / Американці пам'ятають спалахи отруєнь сальмонелою та кишковою паличкою. / Європейці пам'ятають гормони / в телятині та хворобу божевільних корів.
# 7. ХТО ПРАВИЙ
Отже, хто правий?
Усе зводиться до двох філософій. / У Європі працює принцип обережності: заборонити, / поки не доведено, що це безпечно. / У США навпаки: дозволити, поки не доведено, / що це шкодить.
Кожна система має свою ціну. / Європейський підхід може блокувати те, / що насправді нешкідливе, і робить продукти дорожчими. / Американський інколи дозволяє речовину роками, / поки її не заборонять, / як барвник Червоний №3.
І не думай, що Європа бездоганна. / У 2013 році в лазаньях / і бургерах по всьому / континенту знайшли конину замість яловичини. / Ідеальних систем немає.
А що з Україною? / За угодою про асоціацію ми поступово / переймаємо європейські правила безпеки харчових продуктів. / Тож те, що ти їстимеш у майбутньому, / дедалі більше визначатимуть правила Євросоюзу.
Що ж це означає для твоєї тарілки? / Нічого лякаючого. / Якщо ти їси продукти, / виготовлені за українськими й європейськими правилами, / ти їси за правилами, / які діють на твоєму ринку. / А якщо купуєш щось імпортне, / просто читай склад і не бійся слів, / які не розумієш, / але й не вір / кожному гучному відео в інтернеті. / Зокрема й цьому. / Перевіряй.
Головне, що варто запам'ятати: / заборона на ввезення не доказ, / що їжа отруйна. / Це лише доказ, / що дві сторони не погодилися щодо правил.
Хіба це можна їсти? / Відповідь залежить від того, / який паспорт у тебе в кишені.
А ти б з'їв курку, / яку помили у хлорній ванні? / Напиши в коментарях, я прочитаю кожну відповідь.
