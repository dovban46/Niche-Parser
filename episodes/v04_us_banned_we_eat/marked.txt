# 1. ГАЧОК
Уяви: ти приїхав до США з валізою українських смаколиків. / На митниці відкривають її / й дістають звичайне яйце з шоколаду. / Ти ще не встиг нічого сказати, / а тобі вже виписують штраф.
За що? / За іграшку всередині. / Саме так, у Штатах заборонена та сама шоколадна «несподіванка», / яку в нас дають дітям за гривні.
І це лише перше. / Сьогодні сім продуктів, / які в нас лежать / на кожному ринку й у кожному магазині, / а в Америці їх або не можна, / або майже не можна. / Причому в кожного своя причина.
Починаємо з яйця.
# 2. КІНДЕР
Усе почалося у 1938 році. / Тоді американці ухвалили закон про їжу, / ліки й косметику. / А в ньому окремий пункт: / у кондитерському виробі не можна запікати / чи вмуровувати нехарчовий предмет.
Закон писали не проти шоколадних яєць, / бо Kinder тоді ще не існувало. / Але коли яйце / з іграшкою нарешті з'явилося в Європі, / воно потрапило під цю старезну заборону.
Причина офіційна: діти можуть вдавитися дрібною деталлю. / Американська служба з нагляду за / їжею відтак ввела спеціальне правило: / яйця Kinder Surprise затримують / на кордоні без жодної перевірки.
І затримують часто. / Прикордонники повідомляли про понад три / тисячі вилучень із 2010 року. / Причому не лише в посилках, / а й у валізах звичайних туристів.
Але є поворот. / Американці придумали собі Kinder Joy. / Це те саме яйце, / тільки іграшка лежить у окремій половинці. / А значить, вона не вмурована в шоколад, / і закон не порушується. / Офіційного «дозволено» від служби ніхто не писав, / просто його продають.
Тож заборона не / на шоколад і не на іграшку. / А на те, / що вони в одній капсулі. / Ось яка «контрабанда» лежить у нас у холодильнику.
# 3. СИРЕ МОЛОКО
Тепер молоко. / У селі в бабусі ти / точно пив молоко прямо від корови. / Таке, яке ще тепле, з пінкою. / У Штатах із ним цікавіша історія.
Федеральний закон від 1987 року забороняє возити / непастеризоване молоко між штатами для прямого споживання. / Тобто через межу штату його / не повезеш і в магазин не продаси.
І ось що кумедно. / Цю заборону не вигадали чиновники. / Її змусив ухвалити суд. / Громадська організація подала позов, / і суд наказав службі нагляду / за їжею заборонити таке молоко. / Так з'явилося правило.
Але це не заборона «пити сире молоко». / У багатьох штатах / його можна купити просто на фермі. / Тож американець має такий вибір: / або їхати до фермера, або забути.
Причина зрозуміла: сире молоко може принести небезпечні бактерії, / наприклад листерію чи сальмонелу. / Однак у нас дітей таким молоком годували століттями. / Правда й те, / що після кип'ятіння воно безпечніше.
# 4. М'ЯКІ СИРИ
Тепер сири. / Бри, камамбер, ті, / що з білою пліснявою зверху. / Усе, що ти бачиш у супермаркеті, / зроблене з пастеризованого молока. / І це не збіг.
Американське правило таке: / якщо сир із сирого молока, / його мають витримувати щонайменше шістдесят днів. / Лише тоді його дозволено ввозити / чи продавати між штатами. / Правило діє з кінця 1940-х.
Для твердих сирів на кшталт пармезану / чи гауди шістдесят днів не проблема. / А ось м'яким це майже вирок. / Їх їдять свіжими, за тиждень-два, / тож справжній французький камамбер / із сирого молока в Америку, / по суті, не потрапляє.
Але ось сюрприз. / Власні дослідження американської служби / з нагляду за їжею показали: / шістдесят днів може й не робити сир безпечнішим. / Бактерії інколи спокійно переживають витримку. / Тож самі вчені ставлять під сумнів, / чи від цього правила є користь.
Є й застереження. / Правило працює для торгівлі між штатами й ввезення. / Купити такий сир у себе / в штаті на фермі можна далеко не скрізь, / залежить від законів штату.
# 5. ЧОРНА ІКРА
Тепер до розкоші. / Осетрова чорна ікра, / яку в нас на свято кладуть на бутерброд. / Американцям же з нею довелося нелегко.
28 жовтня 2005 року американська служба охорони дикої природи / призупинила ввезення ікри й м'яса білуги / з країн Чорноморського басейну. / Серед них була й Україна.
Чому? / Бо ці країни не надали плану збереження білуги. / Тобто нікому було довести, / що вилов не вбиває вид. / Це дуже цінна риба: вона дорослішає повільно, / тож надмірний вилов дуже її виснажив.
Тоді заборона була майже повною. / Навіть із особистих речей ікру білуги забирали. / Звичайна осетрова ікра, окрім білуги, лишалася можливою.
Що там тепер? / Тут джерела розходяться, тож скажу чесно: / сьогоднішній статус не беруся стверджувати. / Але історія вражає: одне рішення, / і розкіш перетворилася на контрабанду.
# 6. АБСЕНТ
Далі напій, про який ходить найбільше страшилок. / Абсент, зелений, із полином, / нібито від нього бачать галюцинації.
У Штатах він був практично недоступний / із 1912 року й аж до 2007-го. / Майже сто років. / Яка саме була юридична норма, історики сперечаються, / тож скажу так: фактично його не продавали.
Страх був через речовину туйон, / що міститься в полині. / Ніби вона й викликає видіння.
Тільки це міф. / У сучасних дослідженнях туйону в абсенті мізерно мало. / А головна «магія» абсенту просто міцність: / це шістдесят-сімдесят градусів алкоголю. / Не дивно, що після такого все пливе перед очима.
У 2007 році американське бюро / з алкоголю нарешті схвалило перші бренди, наприклад Lucid. / Умова: туйону менше десяти мільйонних часток. / Тобто абсент повернувся, / але вже без своєї страшної слави.
# 7. ЛЕГЕНІ
Тепер найнесподіваніше. / Ти колись їв пиріжки чи холодець із легенями? / Такі дрібниці зазвичай беруть із ринку. / А американцям це заборонено.
У 1971 році американський департамент сільського господарства постановив: / легені худоби не можна використовувати / як їжу для людей. / Для кормів для тварин можна, / а для тарілки ні.
Причина в тому, / що під час забою вміст шлунка / чи рідини можуть потрапити в легені. / А значить, і в продукт.
Через це постраждала й шотландська гордість, хаггіс. / Її традиційно готують із овечих легень. / Тож її довго не пускали до США, / ще й через окреме / правило про ввезення жуйних тварин. / Чи його скасували, у джерелах суперечливо, / тож стверджувати не буду.
А ми їмо легені давно. / У нас їх продають на ринку. / І нікому в голову не прийде, / що десь це шокуюче.
# 8. САМОГОН
І нарешті останній, найукраїнськіший. / Домашній самогон.
У США виробляти міцний алкоголь удома / для себе заборонено на федеральному рівні. / За це загрожує до п'яти років в'язниці / й штраф до десяти тисяч доларів. / А ось пиво й вино вдома варити можна.
Причина здебільшого податкова: / держава хоче збирати акциз із міцного алкоголю. / Є й безпека, / адже погано зроблений дистилят може отруїти.
Але і тут не все так просто. / За повідомленнями юридичних видань, / у квітні 2026 року апеляційний суд / п'ятого округу визнав цю заборону неконституційною. / Чим усе закінчиться й / чи діє закон у повну силу, / ми не знаємо. / Тож стежте за новинами.
# 9. ЧОМУ ТАК
Тепер подивімося на всі сім разом. / Іграшка в яйці. / Тепле молоко від корови. / Сир з білою пліснявою. / Ікра. / Абсент. / Легені. / Самогон.
Між ними немає нічого спільного. / Десь діти, десь бактерії, десь вимираюча риба, / десь податки, а десь просто стара страшилка.
Але є одне. / Усі ці правила писали ще у двадцятому столітті. / Тоді їх писали для тодішніх проблем. / А зараз вони живуть самі, як традиція. / Навіть якщо самі автори сумніваються.
Тож запитання тобі. / Яка з цих сімох заборон здалася тобі найдивнішою? / А яку з цих сімох речей ти / не віддав би ні за що?
Напиши в коментарях. / І пам'ятай: те, що для одних контрабанда, / для інших просто обід.
