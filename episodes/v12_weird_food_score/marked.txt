# 1. ГАЧОК
Гра для вас. / На столі шість страв. / Холодець, квашена капуста, кров'янка, гриби, / кутя з маком і домашній сир. / Усе наше, усе звичайне. / А тепер питання: / яка з них / у чужій країні може викликати жах, / а яка навіть проблеми з митницею?
І це не гриби. / Хоча з грибами теж буде сюрприз.
Я розповім, чому іноземці дивляться на наш стіл з подивом. / І покажу, що їдять вони самі. / А в кінці я назву ту страву, / яку в одній країні офіційно вважають забороненим товаром.
# 2. ПІДПИСКА
Якщо вам цікаво, / підпишіться на канал і поставте лайк. / Тоді ви не пропустите наступні / історії про їжу різних країн.
# 3. ОКСАНА І ГРА
Знайомтеся, Оксана. / Їй шістдесят один, вона з Вінниці, / і сьогодні до неї / на вечерю прийшли гості з-за кордону. / Швед, італієць, ісландка. / Оксана накрила стіл так, / як накривала його тридцять років.
Гості дивляться на стіл і трохи нервово усміхаються. / Нерідко чуєш, як іноземці називають холодець м'ясним желе / і не знають, / з якого боку до нього підступитися. / Оксана ображається. / Адже вона знає, що її стіл найсмачніший.
Тому вона вигадала гру. / Кожна наша страва проти страви з їхньої країни. / Хто з двох дивніший, той отримує бал. / Рахунок будемо вести разом, наші проти чужих. / Шість раундів, і по кожному я називаю рахунок. / Тож не відходьте, / олівець і папірець можуть знадобитися.
Скажу чесно, Оксана впевнена, що виграє. / Вона ж господиня, і стіл її. / Але гості теж привезли з собою пару сюрпризів, / про які вона навіть не здогадується.
Правило одне. / Дивне це не погане. / Дивне це просто чуже. / І ще: сміятися з народів не будемо. / Будемо дивуватися.
Починаємо з найстрашнішого.
# 4. ХОЛОДЕЦЬ І АКУЛА
Холодець. / Бульйон із ніжок і кісток, / який кілька годин варили на повільному вогні. / Потім його розливають по тарілках / і виносять на холод. / Він застигає сам, без жодних добавок. / Секрет у колагені, який виділяється з кісток.
Дивно? / Для когось так. / Але ми принаймні знаємо, / з чого він зроблений.
А тепер Ісландія. / Страва називається хаукарль. / Це м'ясо гренландської акули. / Одна проблема: свіже м'ясо цієї акули отруйне для людини. / У ньому багато сечовини й речовини, / яка розкладається на аміак.
Що роблять ісландці? / Раніше закопували м'ясо / в гравій біля моря на кілька тижнів. / Потім розвішували сушитися ще на місяці. / Сьогодні для цього є спеціальні ємності з дірочками, / але принцип той самий. / Ферментація, щоб небезпечне м'ясо стало їстівним.
Запах? / Аміак. / Дуже сильний. / Гості, які пробували, кажуть, / що це випробування для носа, / а не для язика.
Є ще один факт. / Гренландські акули живуть довше / за будь-яку іншу хребетну тварину. / За оцінками вчених, / найстарші жили понад двісті сімдесят років, / а можливо, і до п'ятисот. / Тобто людина їсть м'ясо істоти, / яка могла бути живою за часів Богдана Хмельницького.
Хто дивніший? / Тут навіть Оксана погоджується. / Бал отримують вони. / Рахунок нуль до одного. / Наші поки відстають.
Але зараз скажу вам міф. / Міф: ісландці їдять це щодня. / Насправді хаукарль це радше святкова страва, / і переважно його подають на зимовому святі. / Як ми кутю на Різдво. / А ще багато ісландців самі признаються, / що гостям пропонують його, / щоб подивитися на їхні обличчя.
# 5. КАПУСТА І СЮРСТРЬОМІНГ
Другий раунд. / Квашена капуста. / Нашатковану капусту посолили, притиснули гнітом, / і через кілька днів вона сама кисне. / Це бродіння, яке роблять корисні бактерії. / А капітан Кук брав кислу капусту в плавання, / щоб моряки не хворіли на цингу.
Нормальна їжа. / Нічого дивного.
А тепер Швеція. / Тут оселедець кладуть у бочки з розсолом, / і він бродить щонайменше пів року. / Потім його консервують у банках. / Бродіння продовжується вже там, тому банки роздуваються. / Страва називається сюрстремінг.
Запах такий, що відкривати банку радять надворі. / А іноді навіть під відром з водою, / щоб запах не розлетівся.
Шведи їдять його раз на рік. / Свято настає у третій четвер серпня. / До цього дня продавати його не заведено. / Подають на тонкому коржі з картоплею і цибулею.
А тепер історія, яка нагадує анекдот, / але це правда. / У Німеччині один орендар розлив розсіл / від цієї риби на сходах будинку. / Сусіди поскаржилися. / Власник виселив його. / Справа дійшла до суду в Кельні, / і у січні вісімдесят четвертого року суд визнав, / що виселення справедливе. / Запах риб'ячого розсолу, як вирішили судді, / виходить за межі того, що можна терпіти. / А за переказами, / на засіданні навіть відкрили банку просто в залі.
А тепер ще одне. / У двотисячному шостому році кілька авіакомпаній, / зокрема Air France, British Airways, / Finnair і KLM, / заборонили цю їжу на борту. / Банки під тиском у літаку можуть луснути. / Деякі називали їх вибухонебезпечними.
Бал знову їм. / Рахунок нуль до двох.
Оксана вже трохи розгублена. / Швед тим часом тихо питає, / чи є в неї сало, / бо вдома він чув, / що в Україні його їдять навіть сирим. / Оксана посміхається: «Це вже наступне відео». / Але гра триває.
# 6. КРОВ'ЯНКА
Третій раунд, і тут цікаво. / Кров'янка. / Каша з кров'ю, яку набивають у кишку. / Гості морщаться: кров? / Справді?
А тепер правда чи міф. / Міф: кров'яну ковбасу їдять тільки в нас. / Насправді вона одна з найдавніших у світі. / Її згадує Гомер в Одіссеї. / У Польщі це кашанка. / В Іспанії морсилья. / У Франції буден нуар. / А у Британії і Ірландії блек-пудинг, / тобто чорний пудинг, де багато вівсяної крупи.
Так, на сніданок в Англії / їдять майже ту саму кров'янку. / З яйцями й тостами.
Тобто швед морщиться на нашу кров'янку, / а англієць не розуміє, що тут дивного. / Тут нічия. / Бали ніхто не отримує.
Рахунок лишається нуль до двох. / Але далі наш виступ, / і Оксана збирається в ліс.
# 7. ГРИБИ
Тепер четвертий раунд. / Гриби. / Для нас це тиха полювання. / Ми їдемо до лісу, повертаємося з відрами, / потім смажимо, солимо, / маринуємо й сушимо на зиму.
А тепер дивіться. / Ще в п'ятдесят сьомому році подружжя Вассон, / Гордон і Віра Павлівна, помітило цікаву річ. / Одні народи люблять збирати гриби, / інші бояться їх. / Слов'янські країни вони назвали гриболюбними. / А англійців, німців і скандинавів, / які живуть біля Північного моря, грибобоязкими.
Тобто людина з Лондона може пройти повз / повний лісу білих грибів і навіть не підозрювати, / що це їжа. / А ми знаємо, / де в нас найкращі місця, / і нікому не кажемо.
Пізніші вчені уточнили, що картина складніша, / і в кожній країні є і ті, й інші. / Але загалом різниця справді є. / Польща, Чехія, Україна, / Білорусь добре відомі як країни грибників.
Бал тут наш. / Бо чужі дивляться на наші відра з подивом. / Рахунок один до двох. / Наші наздоганяють.
Одна порада. / Невідомий гриб не збирайте, / навіть якщо дуже хочеться. / Тиха полювання не повинна ставати останньою.
# 8. СИР
П'ятий раунд. / Домашній сир. / Ми беремо кисле молоко, нагріваємо, / і воно саме перетворюється на ніжний сир. / До нього сметана, цукор або вареники. / Що тут може бути дивним?
А тепер Сардинія. / Італійський острів. / Тут роблять сир, який називається касу марцу. / Це овечий пекоріно, / у якому свідомо живуть личинки сирної мухи.
Так, живі. / Ці личинки поїдають сир зсередини / і роблять його м'яким, майже рідким. / Місцеві кажуть, що це делікатес. / Личинки можуть навіть підстрибувати, коли сир відкривають.
Знайдіть мені іншу страву, яка така дивна. / І ось сюрприз. / В Італії цей сир офіційно не можна продавати. / З шістдесят другого року діє закон, / який забороняє продавати заражені продукти. / Але на самому острові / його знають і зберігають як традиційний продукт.
Ще цікавіше. / У двотисячному п'ятому році вчені / з Сассарі навіть розробили гігієнічний спосіб його виробництва, / щоб сир можна було продавати легально. / Деякі італійські політики й досі просять переглянути заборону.
Бал їм. / Рахунок один до трьох. / Чужі знову попереду.
Але Оксана посміхається. / Бо в неї ще один козир.
# 9. КУТЯ З МАКОМ
Шостий раунд і та сама відкрита петля. / Яка наша страва / в одній країні вважається забороненим товаром?
Кутя. / Пшениця, мед і мак. / А ще маківник, булочки з маком, бублики. / Для нас це ніжний різдвяний смак і дитинство.
А тепер Сінгапур. / Центральне бюро з наркотиків там / на своєму офіційному сайті пише прямо: / мак є забороненим товаром. / Ввезти його, а також їжу з ним, / можна лише за особливою процедурою. / Потрібні документи й лабораторний аналіз, який покаже, / що в насінні немає слідів морфіну.
Чому? / Бо на зібраному насінні / маку можуть залишатися сліди опіатів. / У їжі це мізер, / але закон там дуже суворий. / Тому навіть кілька булочок з маком / у валізі для місцевих митників виглядають / як привід для розмови.
Про деякі інші країни також розповідають подібне, / але це треба перевіряти окремо. / Тому правило просте. / Їдете за кордон, / особливо в країни з суворими законами, / спитайте митницю, що можна везти з їжі. / Не думайте, що все, / що у вас вдома звичайне, звичайне всюди.
Отже, кутя. / Бал нам, і це бал не за дивність, / а за несподіванку. / Рахунок два до трьох.
# 10. ПІДСУМОК
Підбиваємо підсумки. / Три бали отримали чужі страви: акула, / оселедець і сир з личинками. / Два бали наші: гриби і мак. / Кров'янка зіграла внічию. / Остаточний рахунок два до трьох. / Чужі виграли, але ненабагато, / і майже всі дивні страви / в них це страви свят, / а не буднів.
Ми теж їмо багато чого дивного. / Просто нам воно не дивне, / бо ми з ним виросли. / Хто колись їв бабусин холодець чи мамині гриби, / знає, що смак дитинства сильніший за будь-який запах.
Оксана дивиться на гостей. / Швед усміхається і просить рецепт квашеної капусти. / Італієць уже взяв другу порцію холодцю. / А ісландка сказала дивну річ: / вона їсть хаукарль раз на рік, / а ось такий холодець їла б щодня.
Висновок простий. / Дивне це чуже. / А чуже стає рідним, / коли його скуштуєш за чиїмсь столом.
Тепер питання до вас. / Яка страва з іншої країни вас найбільше здивувала? / Напишіть у коментарях. / А якщо ви знаєте страву з нашого столу, / яку іноземці ніяк не можуть зрозуміти, / розкажіть і її.
Дякую, що дивилися. / Підпишіться, поставте лайк, / і до зустрічі в наступному відео.
