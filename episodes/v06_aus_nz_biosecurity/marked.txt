# 1. ГАЧОК
У липні 2022 року мандрівник прилетів / на північ Австралії з острова Балі. / У сумці в нього / лежали два сендвічі з сосискою, / яйцем і сиром та круасан із шинкою. / Звичайний сніданок із фастфуду.
Службовий пес на ім'я Зінта / підійшов до сумки й сів. / Це його сигнал: знайшов.
Штраф склав дві тисячі / шістсот шістдесят чотири австралійські долари. / А міністр сказав, / що це вдвічі дорожче за авіаквиток на Балі.
Сьогодні сім речей, / які ви можете везти / в Австралію чи Нову Зеландію, / навіть не здогадуючись, що ризикуєте тисячами доларів.
Для наочності уявімо Олену. / Вона вперше летить до Сіднея й пакує валізу. / Пройдімо її сумку разом. / Починаємо з найневинішого.
# 2. ЯК ЦЕ ПРАЦЮЄ
Спершу правило, яке економить найбільше. / У літаку тобі дають картку пасажира. / У ній є питання: / чи везете ви їжу, рослини, тваринні продукти.
Якщо відповісти «так» і показати, що саме, штрафу нема. / Співробітник огляне річ. / Далі є три варіанти: її пропустять, / обробять або заберуть.
А якщо відповісти «ні», / а потім у сумці знайдуть яблуко, / це вже порушення. / Причому штрафують не за яблуко. / Штрафують за неправдиву відповідь.
І приховати нелегко. / У аеропортах працюють службові собаки, / яких привчили вишукувати їжу в багажі. / Вони сидять біля людини, / чия сумка пахне м'ясом чи фруктами. / Саме так, як Зінта в Дарвіні.
За повідомленнями медіа, / схожий штраф виписали / й жінці за звичайний сендвіч у багажі. / Тож не думайте, що дрібниця захищає.
# 2. ЯБЛУКО
У валізі Олени лежить яблуко. / Одне. / На дорогу.
В Австралії всі свіжі фрукти треба декларувати. / Це написано в картці пасажира, / яку заповнюють у літаку. / І ось що важливо: якщо задекларувати, штрафу нема. / Яблуко огляне співробітник, і його, найімовірніше, заберуть.
А якщо приховати? / Тоді штраф за свіжі фрукти / й овочі складає шість штрафних одиниць. / Це приблизно дві тисячі австралійських доларів.
Чому так? / Через плодових мух. / Одна комаха з одного яблука може принести шкідників, / які знищать урожай у садах. / Австралія острів, і її природа дуже вразлива.
У сусідній Новій Зеландії те саме. / За незадекларований продукт штраф чотириста новозеландських доларів, / одразу, без суду.
# 3. КОВБАСА
Далі в Олени бутерброд із ковбасою. / Саме це найдорожче.
За незадекларовані м'ясо / чи молочне штраф складає дванадцять штрафних одиниць. / Із 2023 року / це понад три тисячі австралійських доларів. / Заплатити стільки за бутерброд може здатися божевіллям.
Причина називається ящур і африканська чума свиней. / Це хвороби тварин, / які можуть знищити худобу цілої країни. / Після спалаху ящуру на Балі / у 2022 році перевірки різко посилили, / тому й виник той / самий історичний випадок із Макмаффінами.
А цифри вражають. / У 2022 році в аеропортах Австралії вилучили / понад двісті тридцять вісім тисяч небезпечних речей. / А вісімсот шістдесят одна людина / отримала штраф за дванадцять одиниць. / Шестеро з них навіть втратили візи.
Так, штраф це ще не найгірше. / Для іноземця вилетіти назад / без візи може бути дорожче.
# 4. СИР
Тепер сир. / Олена везе шматок домашнього козячого, / бо донька друзів просила.
Приклад із Перта у січні 2023 року. / Двадцятирічний іспанець привіз панчету, / свинину й козячий сир. / Йому виписали три тисячі триста австралійських доларів. / А ще скасували візу, / відправили додому й заборонили в'їзд на три роки.
Він став першим, / кого покарали за нові жорсткіші правила.
Тож сир Олени теж закінчить у смітнику, / а вона має шанс отримати такий самий штраф. / Усе, що з тварини, треба декларувати, / і майже все вилучають.
# 5. МЕД
Мед. / Багато хто думає, / що його не можна везти. / А в Австралії його треба декларувати, / і тоді його оглядають.
У більшості штатів мед можуть дозволити після огляду. / Але в Західній Австралії діють власні правила. / А в Новій Зеландії мед / теж входить до списку речей, / які треба показати співробітнику.
Основна ідея така: / ніхто не штрафує за те, / що ти показав банку меду. / Штрафують за те, що ти її сховав.
Тож Олена задекларує мед, і, можливо, / його навіть пропустять. / Вона відчує полегшення.
# 6. НАСІННЯ Й КВІТИ
А тепер найдорожче. / Насіння й рослини.
Брисбен, травень 2023 року. / У пасажира в брошурі, / в'язаному дитячому одязі й серветках знайшли приховане насіння. / Штраф п'ять тисяч п'ятсот австралійських доларів. / Двадцять штрафних одиниць. / Це був перший такий штраф.
Ще історія, цього разу з Мельбурна. / Індійська акторка Навья Наір прилетіла / з жасмином у волоссі. / Їй виписали штраф тисяча дев'ятсот вісімдесят доларів. / Але штрафували не стільки за квітку, / скільки за відповідь «ні» в картці. / Вона написала, що нічого не везе.
Тож навіть квіти / в зачісці можуть коштувати як відпустка.
# 7. ВЗУТТЯ
Тепер те, про що майже ніхто не думає. / Брудне взуття.
У рюкзаку Олени похідні черевики. / На підошвах земля з минулого походу.
Ґрунт може нести насіння, / гриби й хвороби рослин. / Тому і в Австралії, / і в Новій Зеландії брудне взуття / й спорядження для кемпінгу треба декларувати. / А краще помити перед прильотом.
Нова Зеландія прямо просить чистити черевики / й намети перед польотом. / Без землі й насіння.
# 8. ДЕРЕВО
І остання річ. / Дерев'яні сувеніри.
Олена везе дерев'яну ложку, подарунок для друзів. / Вона не знає, / що в Австралії треба декларувати дерев'яні вироби, / а в Новій Зеландії будь-що з дерева.
Причина в короїдах і жуках, / які живляться деревом. / Для країни з лісами / й садами це серйозна загроза.
Так закінчується огляд сумки. / Яблуко, ковбаса, сир, мед, насіння, / черевики й ложка. / Сім речей, кожна з яких могла коштувати тисячі.
# 9. НОВА ЗЕЛАНДІЯ
А як у сусідів? / У Новій Зеландії за незадекларовану / річ штраф чотириста новозеландських доларів, / одразу, без суду.
У червні 2026 року в Окленді службова собака / на ім'я Софі знайшла незадекларовану їжу / в трьох пілотів. / Кожен заплатив по чотириста доларів. / За обід.
Пропонували підвищити штраф до восьмисот для найнебезпечніших речей, / але це лише проєкт закону. / Станом на зараз чинний штраф чотириста.
І не думайте, що це жарти. / Там справді можуть притягнути й до суду, / якщо річ контрабандна. / Але звичайних туристів чекає саме миттєвий штраф.
# 10. ЧОМУ ТАК
Тепер подивімося, чому такі суворі правила. / Австралія й Нова Зеландія острови. / Їхня природа й сільське господарство унікальні, / а експорт великий. / Одна хвороба може обернутися мільярдами збитків.
В Австралії працюють п'ятдесят шість службових собак. / У 2024 році вони знайшли / понад сорок дві тисячі небезпечних речей.
Але ось головне. / Декларація нічого не коштує. / Не штрафують за те, / що ти показав яблуко. / Штрафують за те, що ти його приховав.
Олена, до речі, все задекларувала. / Яблуко забрали, ковбасу теж, / а мед і ложку пропустили. / Вона вийшла з аеропорту без штрафів / і з легким серцем.
А тепер питання тобі. / Яка з семи речей здалася тобі найнесподіванішою? / І чи ризикнув би ти везти яблуко?
Напиши в коментарях. / І пам'ятай: у цих країнах усе, / що росте чи живе, може бути проблемою.
