# 1. ГАЧОК
Якщо ваша мама чи тато отримує українську пенсію / і живе за кордоном, / є дата, яку не можна пропустити: / 31 грудня 2026. / Хто не встигне, / того виплату можуть зупинити вже з першого січня.
Пані Ніна з Полтави живе / в Кракові в доньки. / Їй шістдесят вісім. / Минулого року вона щось «підтверджувала», тож думає: усе гаразд. / Але чи так це? / Ми перевіримо шість варіантів, які людям пропонують, / і кожен отримає оцінку: зелений, / жовтий або червоний.
Один із цих варіантів звучить дуже розумно, / а насправді може залишити людину без пенсії. / Який саме, скажу в кінці. / А ще є повідомлення, / яке виглядає як від Пенсійного фонду, / але це шахраї. / Покажу, як їх відрізнити.
# 2. ХТО МАЄ ПРОХОДИТИ
Спершу, кому це потрібно. / За поясненнями Пенсійного фонду, / фізичну ідентифікацію проходять ті, / хто за кордоном сто вісімдесят три дні / й більше за календарний рік. / А також ті, хто виїхав через війну, / отримав тимчасовий захист або статус біженця / і не оформив постійне проживання.
Пані Ніна живе в Польщі з тимчасовим захистом. / Тож це про неї.
А от хто виїхав менше ніж / на сто вісімдесят три дні / і без такого статусу, / тому проходити не треба.
# 3. ДЕДЛАЙН
Тепер головне про дату. / Ідентифікація потрібна щороку, і строк один: / до тридцять першого грудня календарного року. / Не «через дванадцять місяців після минулої».
Приклад від самого Фонду. / Хто пройшов у травні 2025 року, / у тому виплата за 2026 рік забезпечена. / А щоб пенсія приходила в 2027-му, / треба пройти знову, до кінця цього грудня.
Пані Ніна пройшла минулого травня. / Значить, цього року їй потрібна нова.
# 3А. ЩО БУДЕ, ЯКЩО ПРОПУСТИТИ
Що буде, якщо дату пропустити? / За повідомленнями медіа з посиланням на Пенсійний фонд, / виплату зупиняють з першого січня 2027 року. / Тобто на картку гроші просто не прийдуть.
Але є й заспокійлива новина. / Сам Фонд пише, / що після проходження ідентифікації виплату поновлять / з дати припинення. / Тобто гроші за місяці паузи не згорять.
Проте між «пройшла» / і «гроші знову приходять» минають тижні. / А пані Ніні, / яка живе здебільшого з цієї пенсії, / такі перерви зайві. / Тому ми не чекаємо грудня.
# 4. ПІДПИСКА
Такі розбори ми робимо для тих, / хто допомагає батькам і рідним за кордоном. / Якщо вам корисно, / підпишіться на канал і поставте лайк. / Тоді нові правила вас не здивують. / А тепер до способів.
# 4А. ЩО ПІДГОТУВАТИ
Перед будь-яким способом підготуйте чотири речі. / Паспорт або ID-картку. / Податковий номер. / Телефон із застосунком «Дія» і доступом до пошти, / яку ви вкажете в заяві. / І стабільний інтернет, / бо відеосеанс триває близько двадцяти хвилин.
Родичам, які допомагають, порада така: / допоможіть з технікою, встановіть застосунок, перевірте пошту. / Але саму ідентифікацію людина проходить сама. / Замість неї цього ніхто не зробить.
# 5. СПОСІБ ПЕРШИЙ: ДІЯ
Перший спосіб. / Дія.Підпис на порталі Пенсійного фонду або / в застосунку Фонду.
Потрібні два пристрої: / комп'ютер із порталом і телефон із «Дією». / Входите на портал, обираєте «За Дія.Підпис», / скануєте код, проходите перевірку за фото / і вводите код із цифр.
Ідентифікація зараховується, коли ви увійшли в кабінет. / Пані Ніна зробила це за вечір, / поки донька вчила її, де натиснути. / Безкоштовно, без черг і без поїздок.
Якщо ж «Дії» немає або вона не відкривається, / не панікуйте: є ще інші способи, / і ми їх розберемо одразу далі.
Оцінка: зелений. / Якщо «Дія» працює і ви вмієте нею користуватися.
Рахунок: зелений один.
# 6. СПОСІБ ДРУГИЙ: ВІДЕО
Другий спосіб. / Відеоконференція з працівником Фонду.
Подаєте заявку на порталі або через контакт-центр. / Дзвінок може бути в Zoom, Viber, WhatsApp, / Telegram, Meet чи Signal. / Потрібні паспорт, податковий номер і відповіді на кілька питань.
Але є пастка. / Сеанс призначають не одразу, за словами Фонду, / приблизно через десять-тридцять днів після заявки. / А ще день і час приходять на пошту, / яку ви вказали. / Помилились в одній літері, / і вас ніхто не знайде. / Пані Ніна б перевірила адресу тричі / й показала доньці.
Тому порада проста: / не лишайте це на кінець грудня. / Подали заявку сьогодні, / і сеанс буде вже в межах місяця.
Оцінка: зелений, але лише якщо подати заявку просто зараз.
Рахунок: зелений два.
# 7. СПОСІБ ТРЕТІЙ: КОНСУЛЬСТВО
Третій спосіб. / Українське консульство.
Тут потрібен документ, що особа жива. / Ви отримуєте його особисто, за попереднім записом, / і надсилаєте до Пенсійного фонду разом із заявою. / Це платна послуга, / а суму краще звірити на сайті свого консульства.
Пані Ніні довелося б їхати до консульства, / чекати запису і платити. / Тож це спосіб на крайній випадок: / коли «Дія» не вийшла, / а відео не вдалося.
Оцінка: жовтий.
Рахунок: зелений два, жовтий один.
# 8. СПОСІБ ЧЕТВЕРТИЙ: СЕРВІСНИЙ ЦЕНТР І БАНК
Четвертий спосіб. / Прийти в сервісний центр Фонду чи в банк.
Для людини в Україні це нормально. / Але пані Ніна в Кракові. / Сервісні центри Фонду є лише в Україні, / а банківська ідентифікація підходить тим, / хто отримує виплату через карту.
Тому з-за кордону цей спосіб практично нереальний.
Оцінка: червоний. / Для пані Ніни.
Рахунок: зелений два, жовтий один, червоний один.
# 9. СПОСІБ П'ЯТИЙ: ПОЛЬЩА
П'ятий спосіб, і він унікальний. / Він стосується Польщі.
Між Україною та Польщею / є окрема угода 2012 року. / Якщо пенсію переказують у Польщу / в євро через польський ZUS, / то це інший режим, / і він не називається ідентифікацією. / Тут щороку до тридцять першого грудня / надсилають «Підтвердження про знаходження особи в живих».
Його засвідчує ZUS, нотаріус або консул. / А надсилають на адресу головного управління Фонду / у Львівській області. / Без цього переказ припиняється / з першого кварталу наступного року.
Тож запам'ятайте: «ідентифікація» і «підтвердження / в живих» це два різні режими. / Який діє для вас, залежить від того, / куди вам перераховують пенсію. / Найпростіше зателефонувати в контакт-центр.
Оцінка: жовтий. / Перевірте, який режим ваш.
Рахунок: зелений два, жовтий два, червоний один.
# 10. НІМЕЧЧИНА І БАНК
А що якщо людина в Німеччині? / За даними медіа, / окремої угоди з Німеччиною немає. / Тож це звичайна ідентифікація, / і пенсія надходить на український рахунок.
Для всіх важливо ще одне. / Пенсія виплачується на рахунок в українському банку, / іноземний рахунок не підходить.
І ще новина про банк. / Укрексімбанк з першого жовтня 2026 припинив виплату пенсій. / Хто банк не змінив, / того виплату передали Укрпошті, / а звідти отримати гроші з-за кордону практично неможливо.
Тож перевірте, де лежить ваша пенсія.
# 10А. НАВІЩО ЦЯ ПЕРЕВІРКА
Навіщо це все? / Загальна мета така: переконатися, / що виплату отримує жива людина, / яка має на неї право. / Це захист і для держави, / і для самих пенсіонерів від шахраїв.
Для пенсіонера це означає один раз / на рік двадцять хвилин біля екрана. / Тож не сприймайте це як покарання. / Це процедура, яку можна пройти спокійно, / якщо не відкладати.
# 11. ШАХРАЇ
Шостий спосіб, і він червоний. / Це повідомлення в месенджері.
«Терміново підтвердьте вік за посиланням». / «Вам належить доплата три тисячі двісті гривень». / «Оберіть трудовий стаж». / Усе це виглядає як від Пенсійного фонду. / Але Фонд не розсилає / в месенджерах вимог перейти за посиланням.
Єдині безпечні адреси: portal.pfu.gov.ua, / застосунок Пенсійного фонду і контакт-центр. / Якщо не розумієте, куди ви потрапили, закрийте сторінку.
А якщо ви вже перейшли / за таким посиланням і ввели дані? / Не соромтеся і не мовчіть. / Зателефонуйте в свій банк, щоб заблокувати картку, / змініть паролі і подайте електронне звернення до кіберполіції. / Чим швидше, тим менше шансів, / що гроші зникнуть.
Оцінка: червоний. / Це шахрайство.
Рахунок: зелений два, жовтий два, червоний два.
# 12. НАЙЧАСТІШІ ПОМИЛКИ
Тепер п'ять помилок, на яких губляться гроші.
Перша: чекати грудня. / Відео призначають через кілька тижнів, / тож пізніше буде пізно.
Друга: вважати, що минулорічної ідентифікації вистачить на 2027 рік.
Третя: помилка в електронній пошті. / День і час сеансу надсилають саме на неї.
Четверта: виїхали з окупованих територій і не повідомили Фонд, / що не отримуєте виплат від Росії. / Це окрема дія, / і вона не замінює ідентифікацію.
П'ята: не змінили банк після Укрексімбанку.
# 13. МІФИ
Тепер швидко: правда чи міф.
«Мені допоможе син, він пройде за мене». / Ні. / Близькі можуть допомогти з підготовкою і записом, / але ідентифікацію проходить сама людина.
«Якщо пропущу, пенсію втрачу назавжди». / За даними Фонду, / після ідентифікації виплату поновлять з дати припинення. / Але гроші за місяці / паузи ви отримаєте не одразу, / тож краще не доводити.
«Ідентифікація платна». / Способи через Дію й відео, / за інформацією медіа, безкоштовні. / Платне тільки консульство.
«Є нові правила з 2027 року». / Нових офіційних змін ми не знайшли. / Дедлайн той самий: тридцять перше грудня.
# 14. ЩО РОБИТИ ЦЬОГО ТИЖНЯ
Ось простий порядок.
Перше. / Відкрийте кабінет на порталі Фонду / і подивіться розділ «Моя ідентифікація»: / чи є відмітка за цей рік.
Друге. / Якщо немає і є «Дія», / пройдіть через Дія.Підпис просто зараз. / Це пів години.
Третє. / Якщо «Дії» немає, / подайте заявку на відеоконференцію сьогодні. / Перевірте пошту, яку вказали.
Четверте. / Якщо ви в Польщі / й пенсію переказують у польський банк, / зателефонуйте в контакт-центр і запитайте, / чи вам потрібне «підтвердження в живих».
П'яте. / Перевірте банк, на який приходить пенсія.
# 15. ПІДСУМОК
Тепер відповідь на питання з початку. / Який спосіб найбільше обманює людей? / Це четвертий: «просто зайти в банк чи сервісний центр». / А ще небезпечніший шостий: / повідомлення від «Фонду» в месенджері.
Підсумуймо. / Дія: зелений. / Відео: зелений, якщо подати заявку зараз. / Консульство: жовтий. / Сервісний центр: червоний для тих, / хто за кордоном. / Польська угода: жовтий, перевірте свій режим. / Месенджер: червоний.
І головне: дата одна, тридцять перше грудня. / Чи проходили ви ідентифікацію з-за кордону? / Який спосіб вибрали? / Напишіть у коментарях, це допоможе іншим.
А якщо в вас є батьки за кордоном, / перешліть їм це відео. / До кінця грудня ще є час.
