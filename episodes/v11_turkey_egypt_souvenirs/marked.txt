# 1. ГАЧОК
Гра для вас. / Ірина повертається з відпустки в Туреччині та Єгипті. / У валізі п'ять речей: камінчик з пляжу, / морська ракушка, таблетки від болю, / монета старовинного вигляду і красивий килим. / Яка з них може коштувати їй свободи?
Це не ковбаса і не алкоголь. / Одну з цих речей майже ніхто / не вважає небезпечною, / а люди кладуть її у валізу кожного літа.
Сьогодні я розповім, / що не можна вивозити з Туреччини та Єгипту, / і покажу реальні історії. / А в кінці назву ту річ, / про яку не знає майже ніхто.
# 2. ПІДПИСКА
Якщо відео стане вам у пригоді, / підпишіться на канал і поставте лайк. / Тоді ви не пропустите наступні поради для мандрівників.
# 3. ІРИНА В АЕРОПОРТУ
Отже, Ірина. / Вона з Дніпра, їй п'ятдесят вісім, / і це її перша відпустка за три роки. / Два тижні моря, сонця і базарів. / Настав останній вечір, і валіза майже готова.
Правила гри прості. / Кожна небезпечна річ це один бал проти Ірини. / А ми будемо рахувати разом.
Одразу скажу головне. / Митник не питає, / чи ви хотіли щось погане. / Він дивиться на те, / що лежить у валізі. / І правила в кожній країні свої, / навіть якщо вдома ви / про них ніколи не чули.
Ірина стоїть над відкритою валізою і вагається. / Камінчик їй подарувало море. / Ракушку вона знайшла сама. / Таблетки взяла про всяк випадок, / бо колись боліла спина. / Монету купила на базарі за копійки. / А килим вирішила везти для доньки.
Кожна з цих речей виглядає звичайно. / Але дивитися на неї будуть не очима відпочиваючої, / а очима митника.
Тому беремо речі по одній. / Спершу найневинніша.
# 4. КАМІНЦІ
Камінчик з пляжу. / Гладенький, теплий, на згадку. / Що тут може бути не так?
Історія з вересня двадцять третього року. / Бельгійське подружжя відпочивало біля Анталії. / Вони підібрали три камені / на пляжі й на вулиці, / щоб покласти їх в акваріум. / В аеропорту їх затримали.
Фахівці музею визначили, що камені римських часів. / Подружжя випустили під судовий контроль, / але виїхати з країни не дозволили. / За повідомленнями, їм загрожувало до дванадцяти років. / Закінчилося штрафом і поверненням додому, / проте нервів вони втратили чимало.
Чому так суворо? / У Туреччині законом захищена історична спадщина. / Це не лише скарби з музею. / Це й фрагменти руїн, старі монети, / уламки давніх будівель. / А пляжі там часто лежать поруч зі старовиною.
Подружжя казало, що знайшло камінці випадково, / а дружина навіть сказала, / що готова заплатити штраф. / Але справу це не закрило одразу. / Спершу експертиза, потім суд.
Бал номер один проти Ірини. / Камінчик краще залишити там, де він лежить.
А якщо купити старовину на базарі, це безпечніше? / Про це трохи пізніше.
# 5. КОРАЛИ Й РАКУШКИ
Їдемо в Єгипет. / Червоне море, Хургада, Шарм. / Яскраві рибки, красиві ракушки. / Хочеться забрати шматочок цього світу додому.
Корали там охороняють. / За даними туристичних джерел, / вивозити їх не можна: ані живі, / ані мертві, ані знайдені на березі. / Штраф, про який пишуть, близько тисячі доларів. / Офіційного тексту я не знайшов, / тож перевіряйте перед поїздкою.
З ракушками складніше. / Чіткої заборони я не знайшов. / Але митник може вирішити, / що це природний об'єкт, / і тоді розмова піде вже з ним. / Тому ракушку краще купити в магазині з чеком, / а не підбирати на дні чи на березі.
Бал номер два? / Скажімо, півбала. / Але з коралом жартувати точно не варто.
# 6. ЛІКИ
А тепер найсерйозніше. / Таблетки від болю в сумочці Ірини. / Це ж звичайні ліки, що тут такого?
У жовтні двадцять сімнадцятого року / в аеропорту Хургади затримали британку Лору Пламмер. / У її валізі було двісті дев'яносто таблеток трамадолу. / Це знеболювальне. / У Британії його виписують за рецептом, / а в неї був рецепт. / Вона везла ліки чоловікові, / у якого болить спина.
Але в Єгипті трамадол прирівняли до наркотиків. / Вирок: три роки в'язниці. / Вона вийшла лише у січні двадцять дев'ятого року, / після помилування президента. / Понад рік за ґратами через таблетки від болю.
Тут головна думка. / Те, що вдома продають в аптеці, / в іншій країні може бути забороненим. / Повного офіційного списку я не знайшов. / Тож правило таке: / перед поїздкою спитайте лікаря і консульство. / Візьміть оригінал рецепта і лист лікаря. / Беріть ліки лише для себе / і лише потрібну кількість.
Бал номер три проти Ірини. / Ось це вже справді небезпечно.
# 7. СУВЕНІРИ З ДАВНИНИ
Четверта й п'ята речі. / Монета старовинного вигляду і килим, / який продавець назвав майже музейним.
Закон про старовину діє в обох країнах. / Справжні старожитності без дозволу вивозити не можна. / А продавець на базарі скаже що завгодно, / бо йому треба продати, / а відповідати доведеться вам.
Що ж робити? / Дивіться на документи. / Якщо річ нова, її продавець підтверджує чеком. / Якщо справжня давнина, потрібен офіційний дозвіл. / Без паперу ризик лягає на вас.
Бал номер чотири. / Але килим із чеком Ірина привезе спокійно. / Гарний сувенір можна купити, / треба лише мати папір.
# 8. ПРАВДА ЧИ МІФ
Перевірмо себе. / Три твердження, і ви відповідаєте самі.
Перше. / Якщо камінь лежав на пляжі, / брати його можна. / Міф. / Бельгійців затримали саме за камені / з пляжу й вулиці.
Друге. / Якщо вдома є рецепт, / ліки можна возити будь-куди. / Теж міф. / У Лори рецепт був. / Але в Єгипті цей препарат заборонений.
Третє. / Якщо продавець сказав, що можна, то можна. / Знову міф. / Він за вас відповідати не буде.
Якщо ви відповіли «міф» тричі, / ви вже не потрапите в історію Ірини.
# 9. ВДОМА, В УКРАЇНІ
Є ще правила нашої митниці, / коли ви вже летите додому. / Вони однакові для всіх країн.
Без мита можна ввезти товарів на загальну суму до тисячі євро / на людину і вагою до п'ятдесяти кілограмів. / Деякі джерела називають інші цифри для наземного кордону, / тож перед поїздкою уточніть на сайті митної служби.
Якщо більше, платите десять відсотків мита / і двадцять відсотків податку з перевищення.
Алкоголь: літр міцного, або два літри вина, / або п'ять літрів пива. / Сигарети: двісті штук. / І пам'ятайте про чеки. / Без чека митник сам / оцінює вартість за ринковою ціною.
# 10. ЯКЩО ВЖЕ ВЗЯЛИ
А що, якщо ви вже взяли щось із цього? / Спокійно, поки ви ще в аеропорту, / все можна виправити.
Перше: нічого не ховайте. / Річ, яку ви лишили / на стійці або викинули до контролю, / це не злочин. / Злочин це коли вас знайшли з нею.
Друге: якщо сумніваєтесь, / спитайте працівника аеропорту / чи митника ще до проходу контролю. / Це нормально, ніхто не злиться.
Третє: якщо вже затримали, не сперечайтеся, / не підписуйте нічого, чого не розумієте, / і одразу зв'яжіться з консульством України. / Номер консульства варто записати ще перед поїздкою.
І четверте: залишайте собі час. / Приїдьте в аеропорт з запасом / і перевірте валізу ще раз, / спокійно, без поспіху.
# 11. ПІДСУМОК
Підсумуємо. / Рахунок: проти Ірини три з половиною бали. / Але вона дізналася про це ще вдома, завдяки вам.
Ось п'ять правил. / Перше: камінці й уламки залиште на місці. / Друге: корали не беріть, / а ракушки краще купити з чеком. / Третє: ліки лише з рецептом і листом лікаря, / а перед поїздкою спитайте консульство. / Четверте: старовину без документів не купуйте. / П'яте: чеки зберігайте аж до дому.
А та річ, / про яку не знає майже ніхто? / Це камінчик. / Найпростіший, найневинніший камінчик з пляжу. / Саме на ньому ламається найбільше мандрівників, / бо ніхто не думає, що він небезпечний.
Якщо це вам допомогло, / поділіться відео з тим, / хто збирається на море. / А в коментарях напишіть, / що ви привезли з відпустки найдивнішого.
